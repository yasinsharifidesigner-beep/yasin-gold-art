# Yasin Gold Art — prototype

A Persian, RTL, mobile-first Next.js 14 prototype for a jewelry design academy, CAD marketplace, and bespoke design atelier.

## Run

Requires Node.js 18.17 or later and npm. From this directory:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For a production check, run `npm run build && npm start`.

## Included

- Home, course catalog and gated lesson demo, CAD marketplace, bespoke order wizard, journal reader, atelier story, contact, challenges, profile, and standalone auth routes.
- Persian RTL layouts, responsive mobile dock, search, cart drawer, product preview, pricing selection, filters, local demo auth, sample STL download after demo checkout, and PWA manifest/service worker.
- Locally generated jewelry hero image at `public/hero-ring.png`.

## Demo boundaries

Prices, course and product metadata, testimonials, and metrics are sample content. Auth, OTP, payment, orders, booking, and partner contact details require production services before launch. The sample STL is a simple torus and is **not suitable for jewelry production**. The on-page flows label demo states. Real CAD files and verified workshop partner marks must be supplied by the business.
